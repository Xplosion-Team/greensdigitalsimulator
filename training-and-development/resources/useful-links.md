## 🔍 Search Tips

### Finding Solutions
**Google Search Pattern**:
```
"react native" + [your problem] + "expo"
"typescript" + [error message]
"accessibility" + [feature] + "seniors"
```

**Example**:
```
"react native text to speech expo"
"typescript function type definition"
"accessibility large fonts seniors"
```
